> 本文件是「通用界面与交互规范」在**本项目**的扩展：只写业务词表、枚举映射、口径与页面清单，不重复通用条款。

## 1. 术语表（一词一义）

| 术语 | 唯一用词 | 禁止说法 | 定义 |
| --- | --- | --- | --- |
| 被计量的物理对象（电表/水表/冷量表…） | **设备**（表计同义时一律写"设备"） | 表具、点位、仪表、meter | 台账实体，`Device`；编号形如 `MTR-EL-00123` |
| 设备的一次时间片记录 | **抄表记录** | 读数条、采集点、数据点 | `Reading`；一个设备在一个时间片一条 |
| 台账列表里的一行 | **台账行** | 记录项、条目 | `LedgerRow` = 设备 + 最近抄表 + 本月累计 + 环比 + 覆盖率 |
| 聚合用的固定时间单元 | **时间桶** | 时间点、分片、格子 | 由粒度决定（15 分钟桶/小时桶/日桶/月桶） |
| 时间窗口 | **统计周期** | 时间范围、日期区间 | 闭区间 `from..to`，含起止两天 |
| 聚合统计的切分方式 | **维度** | 角度、分类方式 | `time / area / deviceType / tariff / loop` |
| 被统计的量 | **指标** | 数据项、字段 | `energy / cost / intensity / demand / loadRate / co2` |
| 指标的计算说明 | **口径** | 算法、定义、公式说明 | 一句话写清范围 + 粒度 + 是否含估算值 |
| 参与统计的记录数/设备数 | **样本量** | 数据量、条数（口语除外） | 一律写 `样本量 n=…` |
| 数据截止与缺失情况 | **数据新鲜度** | 更新时间、同步状态 | 最近抄表时间、有读数设备数、缺失率 |
| 数据可信程度 | **抄表质量** | 数据状态、异常标记 | `normal / estimated / missing` |
| 数据来源 | **采集方式** | 数据源类型 | `manual`（人工抄表）/ `auto`（自动采集） |
| 电费分时 | **尖峰平谷** | 峰谷、费率段 | `sharp 尖 / peak 峰 / flat 平 / valley 谷` |
| 导出与下载的分析产物 | **分析报表** | 报告、文件、导出物 | `ReportDocument`，模板 + 周期 + 维度 |
| 筛选/排序/分页的组合状态 | **查询状态（QueryState）** | 筛选条件、当前视图 | 全部进 URL |

**单位用词**：`kWh`、`m3`、`t`、`GJ`、`kW`、`kWh/m2`。不要写成 `度`、`吨`、`立方`。

## 2. 业务状态枚举与颜色映射

颜色只用于**标签/状态点**，不改整行背景；Token 见 `app/app.css`。

### 2.1 设备状态 `DeviceStatus`

| 值 | 标签 | 底色/文字 Token | `statusTone` | 说明 |
| --- | --- | --- | --- | --- |
| `online` | 在线 | `bg-success-soft` / `text-success` | success | 近 24h 有自动采集读数 |
| `offline` | 离线 | `bg-warning-soft` / `text-warning` | warning | 近 3 天无读数；台账仍保留 |
| `fault` | 故障 | `bg-danger-soft` / `text-danger` | danger | 采集或计量异常，需现场处理 |
| `archived` | 已归档 | `bg-surface-2` / `text-fg-muted` | neutral | 退出统计，仅历史查询可见 |

### 2.2 抄表质量 `ReadingQuality`

| 值 | 标签 | Token | 展示位置 |
| --- | --- | --- | --- |
| `normal` | 正常 | `text-success` + `bg-success-soft` | 明细表、抽屉 |
| `estimated` | 估算 | `text-warning` + `bg-warning-soft` | 估算值必须在第一层可见，不许只藏在明细里 |
| `missing` | 缺失 | `text-danger` + `bg-danger-soft` | 缺口不计入合计，需在口径里写明 |

### 2.3 采集方式 `ReadingSource`

| 值 | 标签 | 说明 |
| --- | --- | --- |
| `manual` | 人工抄表 | 有抄表人/批次概念，审计场景用绝对时间 |
| `auto` | 自动采集 | 默认；数据新鲜度按它计算 |

### 2.4 尖峰平谷 `TariffPeriod`

| 值 | 标签 | Token | 典型时段 |
| --- | --- | --- | --- |
| `sharp` | 尖 | `text-tariff-sharp` | 夏季/冬季极端负荷时段 |
| `peak` | 峰 | `text-tariff-peak` | 09:00–11:30、14:00–17:00 |
| `flat` | 平 | `text-tariff-flat` | 其余工作时段 |
| `valley` | 谷 | `text-tariff-valley` | 22:00–次日 06:00 |

图例、饼图、占比条必须用上表固定配色，不随序列顺序变化。

### 2.5 时间粒度 `Granularity` 与维度 `Dimension`

`15min` 15 分钟 / `hour` 小时 / `day` 日 / `month` 月。
`time` 时间 / `area` 区域 / `deviceType` 设备类型 / `tariff` 时段 / `loop` 回路。

## 3. 告警级别枚举

| 级别 | 标签 | 组件 | Token | 是否打断 | 触发示例 |
| --- | --- | --- | --- | --- | --- |
| info | 提示 | `Alert variant="info"` | `bg-info-soft` / `text-info` | 否 | 粒度已自动降级、口径说明 |
| success | 成功 | `Alert variant="success"` | `bg-success-soft` / `text-success` | 否 | 导出生成完成 |
| warning | 警告 | `Alert variant="warning"` | `bg-warning-soft` / `text-warning` | 否（第一层可见即可） | 覆盖率 < 90%、存在离线设备、估算值占比 > 5% |

| 归属字段 | 格式 | 示例 | 用途 |

## 7. 指标口径、时间窗口与样本量

### 7.1 指标定义

| 指标 | 标签 | 口径（一句话，直接用于 `Stat.formula` / 表头说明） | 样本量 n = |
| --- | --- | --- | --- |
| `energy` | 能耗量 | 统计周期内所有参与设备的时间桶消耗量之和（含估算值，缺失不计） | 参与计算的抄表记录条数 |
| `cost` | 能耗成本 | Σ(分时段电量 × 对应分时电价)；无电价时段的量按平段计 | 有电价时段的记录条数 |
| `intensity` | 单位面积能耗 | 能耗量 ÷ 归属面积合计（`areaM2 > 0` 的设备） | 参与计算的设备台数 |
| `demand` | 最大需量 | 统计周期内各时间桶需量的最大值（kW） | 有效需量记录条数 |
| `loadRate` | 负荷率 | 平均负荷 ÷ 最大需量 × 100% | 有效读数条数 |
| `co2` | 碳排放 | 能耗量 × 排放因子（电 0.5703 kgCO₂/kWh，其他按介质系数） | 参与计算的记录条数 |

百分比类指标（占比、覆盖率、负荷率、同比、环比）**必须**附样本量：卡片写 `样本量 n=…`，表格列头写「（n=…）」，报告表头写 `header` 行。

### 7.2 时间窗口

- 闭区间：`from..to`，两端都含；日粒度下"今天"的数据只到最近一个完整时间桶。
- 时间桶左闭右开，标签用桶起点（`formatBucket`）。
- 性能护栏：`15min` 窗口 > 7 天、`hour` 窗口 > 90 天时自动降一档粒度，并在 `notes` 里写明「已从 X 降级到 Y，原因：数据量」。
- 在线率/新鲜度按"最近一次成功采集"计算，不用请求时间。

### 7.3 对比口径

| 类型 | 定义 | 无基期时 |
| --- | --- | --- |
| 同比 `yoy` | 与去年同期等长窗口比较 | 显示 `—`，不显示 0% |
| 环比 `mom` | 与前一个等长窗口比较 | 显示 `—`，不显示 0% |

`Stat.deltaKind` 必须与文案一致：写「同比」就传 `yoy`，不要用「环比」标签配同比数值。
变化方向的好坏：能耗/成本/碳排默认「越低越好」（上升用 `danger` 色），覆盖率/负荷率传 `deltaPolarity="higher-is-better"`。

### 7.4 数据质量与新鲜度（必须第一层可见）

- 新鲜度：`lastReadingAt`、`deviceWithReading / deviceTotal`、`missingRatio`。
- 质量分布：`normal / estimated / missing` 三档计数；估算值占比 > 5% 升为 warning。
- 覆盖率 < 90% 的设备在台账第一层标记；缺失率 > 20% 用 danger 级别告警并给出「切到日粒度」等下一步。

## 8. 页面清单与页面模式

| 路由 | 页面 | 页面模式 | 第一层必须给判断 | 第二层 | 归属 |
| --- | --- | --- | --- | --- | --- |
| `/` | 总览看板 | 分析看板（KPI + 主趋势 + 构成 + 排名） | KPI（含样本量与口径）、新鲜度、质量告警 | 明细表披露、`notes` 口径列表 | worker-gamma |
| `/analysis` | 多维分析 | 分析看板（维度/粒度切换 + 分组 + 热力 + 环比） | 当前维度、粒度、样本量、降级提示 | 明细序列表、环比对比表 | worker-gamma |
| `/devices` | 设备与抄表台账 | 列表-详情（QueryState + 行抽屉） | 筛选结果总数、当前页范围、数据质量 | 行抽屉：最近抄表明细、覆盖率、本月累计 | worker-delta |

### 8.1 长任务、保留期与取消

| 任务 | 触发 | 取消 | 保留期 | 失败处理 |
| --- | --- | --- | --- | --- |
| 报表生成 / 导出 | `生成报表预览`、`下载 CSV/Markdown` | 前端 `AbortController` 取消请求；离开页面即放弃 | 不落盘、不保留（按需生成） | 错误态给「重试」，文案写清失败阶段（生成 / 编码 / 下载） |
| 大窗口查询 | 切换粒度/周期 | 只应用最新请求（旧响应丢弃） | — | 提示「已降级粒度，详见口径」 |

## 9. 待补项（下次会话补齐）

1. **分时电价数值未进领域契约**：`cost` 口径引用"分时电价"，但 `types.ts` 无电价表。当前以 mock 源内部常量实现；接真实 API 时需在契约里补 `TariffPrice`。
2. **碳排放因子来源**：现按公开系数占位，需补一份带版本号的因子表（电/水/气/汽/冷）。
3. **抄表人/批次**：`Reading` 有 `source: manual`，但没有抄表人与批次字段；审计场景需要时补 `operatorId`、`batchId`。
4. **设备状态与 `statusTone` 的最终对齐**：第 2.1 节是本项目约定；若 `dictionary.ts` 的 `statusTone` 实现不同，以本节为准并同步修字典表。
5. **L2 全选（筛选结果）**：当前只实现 L1（当前页）；需要批量操作全量设备时，补服务端"按 QueryState 精确计数 + 按条件执行"的接口。
6. **数据覆盖区间**：`coverage()` 现已用于日期选择器 min/max；真实源接入后需在页面上直接显示"数据覆盖 X 至 Y"。
7. **单位自动换算**：`formatEnergy` 的 K/M 阈值需与报表口径统一（当前 K=1000、M=1e6），待 alpha 固化后回填本节。

## 10. 基础件调用口径（本项目实现约定）

这部分写清楚组件库里不直观的坑，页面调用前先看一眼，避免各页自己另造一套。

| 组件 | 约定 |
| --- | --- |
| `Stat` | `sampleSize` 必填；`delta` 必须配 `deltaKind`（默认 `mom`）；`formula` 写第 7.1 节的口径原句；能耗类上升用默认 `deltaPolarity="lower-is-better"` |
| `TableContainer` | 负责横向滚动 + 最大高度；列多时**不许**压缩列宽，用 `TableContainer` 横向滚动 |
| `TableCell` | 默认单行截断 + `title` 悬浮；数字列传 `truncate={false}` 并加 `tnum`、`align="right"` |
| `TableCaption` | 写口径 + 样本量 + 数据新鲜度，不是装饰 |
| `Drawer` / `Dialog` | 必须给 `title`；`footer` 不传时渲染固定「取消 + 确认」；Esc / 点遮罩可关闭 |
| `Popover` | 决策型浮层要给 `title` + `onConfirm`（自动带「取消 + 确认」）；内容自带内边距 |
| `Select` | 值是普通字符串；"全部"用哨兵值（如 `"all"`）而不是空串 |
| `Checkbox` | 表头三态用 `indeterminate`；范围只代表当前页（L1） |
| `FilterChip` | 每个已生效条件一个 chip，必须给 `onRemove` |
| `DateRangeField` | 非法区间（起点 > 终点、超出覆盖范围）不触发 `onChange`，只在下方报错 |
| `Pagination` | `total` 必须是精确总数；任何筛选/排序/pageSize 变化由页面重置到第 1 页 |
| `EChart` | 高度固定（默认 280）；`ariaLabel` 必填；图表旁必须给表格化数据出口 |
| `CHART_COLORS` | 图表唯一配色来源（令牌 `--color-series-1..8`）；尖峰平谷图例用第 2.4 节固定色 |
| presets 入参 | `items` 同时接受 `GroupTotal`（`label/energy`）与 `DeviceRank`（`name/value`）；`series` 直接传 `TimeSeries[]` |
